# ReaLiDAR: Material-Aware LiDAR Simulation for Robust 3D Sensing in Complex Environments

This repository hosts the [project page](https://real-lidar.github.io/) of ReaLiDAR.
The official implementation is available at [zju-muslab/ReaLiDAR](https://github.com/zju-muslab/ReaLiDAR).

**Accepted by CCF Transactions on Pervasive Computing and Interaction.**

## Authors

Yuli Wu, Duheng Pan, Puhe Hao, Yu'an Huang, Feng Lin, Li Lu\*<br>
